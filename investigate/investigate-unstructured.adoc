= Analiza datos no estructurados en AI Data Engine
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Cuando el almacenamiento basado en archivos crece de forma inesperada, filtra por hora del último acceso, tamaño del archivo y propietario para identificar qué archivos están ocupando capacidad. Por ejemplo, un administrador de almacenamiento puede identificar terabytes de instantáneas de VM a las que no se ha accedido desde hace más de un año y evaluar si conviene archivarlas, eliminarlas o conservarlas.



[[before-you-begin]]
== Antes de empezar

* Has conectado al menos una fuente de datos y se está escaneando. Consulta link:../data-sources/connect-data-source.html["Conecta una fuente de datos"].




[[find-cold-or-stale-files-by-last-access-time]]
== Buscar archivos inactivos u obsoletos por tiempo de acceso

Busca archivos a los que no se haya accedido según los umbrales de datos inactivos u obsoletos de tu organización mediante filtros basados en fechas. Defines estos umbrales, incluida la marca de tiempo que usa cada uno, en la configuración de clasificación de datos. Consulta link:../administer/configure-settings.html["Configurar los umbrales de clasificación de datos y el análisis de acceso"].

.Pasos
. En la interfaz de usuario de AI Data Engine, selecciona *Investigación*.
+
La pestaña «Sin estructurar» aparece seleccionada de forma predeterminada.

. Selecciona *Add filter* y, a continuación, selecciona *Last accessed*.
. Selecciona un intervalo de tiempo que se ajuste a tu umbral de datos inactivos, por ejemplo *1+ año*.
. Para centrarte en los mayores consumidores, vuelve a seleccionar *Add filter*, luego selecciona *File size* y establece un valor mínimo, por ejemplo *>1 GiB*.
+
Los filtros aplicados aparecen como etiquetas debajo de la barra de filtros. La tabla de resultados y el recuento de elementos se actualizan a medida que añades cada filtro.





[[group-results-by-owner]]
== Agrupa los resultados por propietario

Agrupar por propietario te ayuda a entender quién tiene la mayor cantidad de datos potencialmente recuperables antes de decidir dónde actuar.

.Pasos
. Una vez aplicados los filtros, selecciona el menú desplegable *Ver por*.
. Selecciona *Owner*.
+
Los resultados se reorganizan para mostrar el número total de archivos y el tamaño por propietario. Selecciona cualquier fila de propietario para expandirla y ver sus archivos individuales.





[[review-file-details]]
== Revisar los detalles del archivo

Comprueba que un archivo se ajuste al ámbito deseado antes de realizar ninguna acción. Selecciona cualquier fila de archivo para abrir el panel de detalles.

El panel de detalles muestra el sistema del archivo, el repositorio de almacenamiento, la ruta, el tamaño, las marcas de tiempo, el acceso, el propietario del archivo y cualquier etiqueta o política aplicada. El campo *Duplicados* muestra el número de copias duplicadas del archivo. Comprueba el sistema y el propietario antes de archivar o eliminar.



[[find-duplicate-files]]
== Busca archivos duplicados

Mira hasta qué punto están extendidos los archivos duplicados antes de decidir dónde limpiar. El filtro *Duplicados* muestra todos los archivos que tienen una o más copias idénticas en otras partes del catálogo.

.Pasos
. En la interfaz de usuario de AI Data Engine, selecciona *Investigación*.
+
La pestaña «Sin estructurar» aparece seleccionada de forma predeterminada.

. Selecciona *Add filter* y después selecciona *Duplicates*.
+
La tabla de resultados muestra los archivos que tienen copias duplicadas.

. Para ver todas las copias de un archivo concreto y su ubicación, selecciona el nombre del archivo y, a continuación, selecciona *Ver detalles* junto a *Duplicados*.


Para revisar las copias y limpiarlas, consulta link:take-actions.html["Investiga y limpia los archivos duplicados"].



[[act-on-results-or-save-as-a-policy]]
== Actúa según los resultados o guárdalo como una política

Una vez identificados los archivos que quieres abordar, selecciona uno o varios elementos con las casillas de selección de la tabla de resultados.

* Para realizar una acción inmediata, consulta link:take-actions.html["Actúa sobre tus datos"].
* Para guardar los criterios de filtrado para la supervisión continua, selecciona *Crear política* en la barra de herramientas de filtrado. Consulta link:../policies/create-policy.html["Crear una política"].


Para descargar los resultados filtrados de la pestaña «Sin estructurar», selecciona image:icon_download_file.png["Descargar"].
