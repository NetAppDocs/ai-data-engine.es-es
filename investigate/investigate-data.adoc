= Analiza tus datos en AI Data Engine
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Cuando necesites averiguar qué está consumiendo almacenamiento, identificar qué tablas de bases de datos están creciendo sin control o localizar directorios con permisos de acceso excesivamente amplios, utiliza filtros de metadatos para analizar tus datos en todos los sistemas conectados.

image::aide_mo_ga_investigation_page.png[Vista de investigación de AI Data Engine]



[[choose-a-starting-point]]
== Elige un punto de partida

Selecciona *Investigation* en la navegación izquierda para abrir la vista. También puedes abrir la vista Investigation desde el dashboard seleccionando *Investigate* en la tabla _Top data resources by reclaimable storage_, lo que aplica automáticamente un filtro para ese recurso.

La sección *Investigation* se organiza en tres pestañas: *Unstructured*, *Directories* y *Structured*. Selecciona la pestaña que coincida con el tipo de datos que estás investigando.

[cols="1,2,1"]
|===
| Pestaña | Úsalo cuando quieras | Más información 


| *Sin estructura* | Detecta datos basados en archivos inactivos, obsoletos o duplicados en volúmenes NFS y SMB | link:investigate-unstructured.html["Analiza datos no estructurados"] 


| *Directorios* | Revisa los permisos a nivel de directorio y encuentra rutas ampliamente accesibles | link:investigate-directories.html["Investigar directorios"] 


| *Estructurado* | Identifica las tablas de bases de datos de gran tamaño o en desuso que consumen espacio de almacenamiento | link:investigate-structured.html["Investiga los datos estructurados"] 
|===
La etiqueta de cada pestaña muestra un resumen de los elementos de ese tipo (por ejemplo, "No estructurados (30.4M)").
