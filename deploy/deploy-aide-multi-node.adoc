= Desplegar AI Data Engine como una implementación de varios nodos
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Implementa AI Data Engine (AIDE) como una implementación multinodo desde NetApp Console con el asistente de implementación. El asistente te guía para seleccionar la ubicación de instalación, elegir un tamaño de configuración y ejecutar el comando de instalación en tu clúster de Kubernetes.


IMPORTANT: Si los nodos del clúster o el host del instalador solo pueden conectarse a internet a través de un proxy de salida, usa link:deploy-aide-multi-node-proxy.html["Implementar AI Data Engine como una implementación multinodo con un proxy"] en su lugar.

.Antes de empezar
*Permisos y acceso*

* Tienes permisos de _administrador de la organización_ o superiores en NetApp Console.
* Tienes un kubeconfig con acceso cluster-admin al clúster de destino. Si `kubectl` no está en tu `PATH`, el instalador lo descarga al directorio tools.


*Clúster de Kubernetes*

* Tu clúster de Kubernetes cumple los requisitos previos para clústeres de varios nodos descritos en link:multi-node-prerequisites.html["Requisitos previos para la implementación de AIDE en varios nodos"] y link:aide-requirements.html["Requisitos AIDE"].
* El `aide` espacio de nombres existe en el clúster antes de ejecutar el comando de instalación.
* Los nodos que programan las cargas de trabajo de AI Data Engine tienen las etiquetas de nodo descritas en link:multi-node-prerequisites.html#node-labels["Etiquetas de nodos"].
* Hay un StorageClass configurado (nombre predeterminado: `aide-sc`) disponible en el clúster y se usa para los servicios de respaldo con estado de AIDE.


*Almacenamiento y NetApp Console*

* Hay un servidor NFS con una ruta exportada disponible y accesible desde el clúster para el volumen de configuración de AIDE.
* Un agente de NetApp Console https://docs.netapp.com/us-en/console-setup-admin/concept-agent-install-options.html#agent-console-deploy["está implementado"^] al que se pueda acceder desde los nodos del clúster. La dirección IP del agente de Console es necesaria para ejecutar el comando de instalación.



NOTE: Utiliza el instalador únicamente para la primera instalación de AIDE. No lo utilices para actualizar AIDE. Tras la instalación, el operador de AIDE se encarga de las actualizaciones. Para obtener información sobre las actualizaciones, ponte en contacto con NetApp Support.

.Pasos
. En NetApp Console, ve a *AI data hub* > *AI Data Engine*.
+
Aparece la página de inicio de AI Data Engine.

. Selecciona *Deploy AI Data Engine*.
. Selecciona la opción de implementación *Multi-node* y selecciona *Next*.
. Selecciona el tamaño de tu configuración:
+
** *Pequeño*: recomendado para entornos con hasta aproximadamente 1.000 millones de archivos.
** *Medio (predeterminado)*: recomendado para entornos con hasta aproximadamente 3 mil millones de archivos.
** *Grande*: recomendado para entornos con hasta aproximadamente 6 mil millones de archivos.
+
Estos tamaños son valores de referencia recomendados, no límites estrictos. Una implementación de AIDE con varios nodos requiere un dimensionamiento personalizado con NetApp para entornos con más de 6.000 millones de archivos; consulta link:aide-requirements.html#flexible-sizing-multi-node["directrices flexibles de dimensionamiento"] para obtener más detalles.



. Copia el comando de instalación que aparece en el asistente en un editor.
+
El asistente genera el comando de instalación con el tamaño de configuración que selecciones.

. Ejecuta el comando de instalación desde un host que pueda conectarse a tu clúster de Kubernetes.
+
Si el instalador te pregunta si deseas configurar un proxy de salida, introduce `n`.

+

NOTE: La instalación tarda unos 30 minutos en completarse. Es posible que se produzcan tiempos de espera y reintentos, y esto es normal.

. Responde a las solicitudes de confirmación del instalador para continuar con la instalación.
+
** El instalador muestra el clúster de Kubernetes seleccionado por tu kubeconfig, incluido el contexto, el nombre del clúster y el servidor API. Responde «sí» solo si ese es el clúster que piensas usar. Si es el clúster equivocado, detén el instalador, selecciona el contexto de kubeconfig correcto y vuelve a ejecutar el instalador.
** El instalador te pide que confirmes que los requisitos previos para una implementación de varios nodos están completos. Responde yes para continuar.
** El instalador detecta la dirección IP del nodo que ejecuta AI Data Engine NGINX ingress y te pide que la confirmes. Pulsa Intro para mantener la dirección mostrada o escribe una dirección diferente. Usa una dirección a la que se pueda acceder desde fuera del clúster. Si la dirección detectada es una dirección interna del clúster, escribe en su lugar la dirección accesible. No introduzcas la dirección del agente de Console.


. Vigila la pantalla de progreso hasta que aparezca la pantalla de éxito y confirme que la instalación de AIDE ha finalizado.


.Resultado
Tu implementación multínodo de AI Data Engine ya está desplegada y conectada a NetApp Console. Ahora puedes link:../data-sources/connect-data-source.html["conectar una fuente de datos"] para iniciar el análisis.
