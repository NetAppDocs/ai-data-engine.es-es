= Implementar AI Data Engine Enterprise
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Despliega AIDE Enterprise desde NetApp Console utilizando el asistente de despliegue. El asistente te guía para seleccionar tu ubicación de instalación, elegir un tamaño de configuración y ejecutar el comando de instalación en tu clúster RKE2.

.Antes de empezar
* Tu organización tiene acceso a la versión preliminar privada de AI Data Engine en NetApp Console. Ponte en contacto con tu representante de NetApp para solicitar acceso y poder implementar AI Data Engine.
* Tienes permisos de _administrador de la organización_ o superiores en NetApp Console.
* Tu clúster RKE2 cumple los requisitos previos de nodos Enterprise descritos en link:aide-requirements.html["Requisitos AIDE"].
* Necesitas permisos de «sudo» (o de «root») en el equipo desde el que ejecutas el comando de instalación.
* Hay un servidor NFS con una ruta exportada disponible y accesible desde el clúster para el volumen de configuración de AIDE.
* Un agente de NetApp Console https://docs.netapp.com/us-en/console-setup-admin/concept-agent-install-options.html#agent-console-deploy["está implementado"^] y accesible desde los nodos del clúster. Se necesita la dirección IP del Console Agent para ejecutar el comando de instalación.
* kubectl está disponible en el equipo desde el que ejecutas el comando de instalación, con acceso cluster-admin al clúster de destino.
* El espacio de nombres de Kubernetes de destino (predeterminado `aide`) ya existe en el clúster antes de ejecutar el comando de instalación.
* Hay un StorageClass configurado (nombre predeterminado: `aide-sc`) disponible en el clúster y se usa para los servicios de respaldo con estado de AIDE.


.Pasos
. En NetApp Console, ve a *AI data hub* > *AI Data Engine*.
+
Aparece la página de inicio de AI Data Engine.

. Selecciona *Deploy AI Data Engine*.
. Selecciona la opción de implementación *Enterprise* y selecciona *Siguiente*.
. Copia el comando de instalación preconfigurado que aparece en el asistente a un editor.
. Selecciona el tamaño de tu configuración:
+
** *Pequeño*: recomendado para entornos con hasta aproximadamente 1.000 millones de archivos.
** *Medio (predeterminado)*: recomendado para entornos con hasta aproximadamente 3 mil millones de archivos.
** *Grande*: recomendado para entornos con hasta aproximadamente 6 mil millones de archivos.
+
Estos tamaños son valores de referencia recomendados, no límites estrictos. AIDE Enterprise admite entornos con más de 6.000 millones de archivos mediante escalado horizontal; consulta link:aide-requirements.html#flexible-sizing-enterprise["directrices flexibles de dimensionamiento"] para obtener más detalles.



. Tanto si se trata de configuraciones pequeñas como grandes, adapta el comando de instalación para que se ajuste al tamaño elegido: `--flavor <small|medium|large>`
. Ejecuta el comando de instalación con los ajustes del tamaño de la configuración que correspondan desde tu host de destino con acceso a tu clúster RKE2 mediante kubectl.
+

NOTE: La instalación tarda unos 30 minutos en completarse. Es posible que se produzcan tiempos de espera y reintentos, y esto es normal.

. Cuando se te solicite, confirma la dirección IP del host y el ID de usuario para continuar con la instalación.
. Vigila la pantalla de progreso hasta que aparezca la pantalla de éxito y muestre «AI Data Engine deployed».


.Resultado
AI Data Engine Enterprise está implementado y conectado a NetApp Console. Ahora puedes link:../data-sources/connect-data-source.html["conectar una fuente de datos"] para iniciar el análisis.
