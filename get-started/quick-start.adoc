= Inicio rápido para AI Data Engine
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Pon en marcha AI Data Engine (AIDE) implementando el servicio, conectando tus fuentes de datos e iniciando tu primera investigación. También puedes permitir que los clientes de IA busquen en tus metadatos mediante acceso controlado a la IA.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["1"] link:../deploy/aide-requirements.html["Revisa los requisitos y selecciona un tipo de implementación"]
[role="quick-margin-para"]
Revisa los requisitos y consulta link:../deploy/deployment-overview.html["conoce los tipos de implementación"] para decidir si instalar una implementación de AIDE de un solo nodo o de varios nodos.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["Dos"] link:../deploy/deployment-overview.html["Implementar AI Data Engine"]
[role="quick-margin-para"]
Implementa un link:../deploy/deploy-aide-single-node.html["Implementación de AIDE en un único nodo"] o un link:../deploy/deploy-aide-multi-node.html["Implementación multinodo de AIDE"] desde NetApp Console. La página de configuración te guía para seleccionar la ubicación de instalación y el tamaño de la configuración, y para ejecutar el comando de instalación. Si tu host o clúster solo accede a internet a través de un proxy, utiliza link:../deploy/configure-proxy.html["implementar con un proxy"] en su lugar.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png["Tres"] link:../data-sources/connect-data-source.html["Conecta una fuente de datos"]
[role="quick-margin-para"]
Conecta una fuente de datos para iniciar el escaneo. AI Data Engine cataloga los metadatos de las fuentes de datos que conectes.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-4.png["Cuatro"] link:../investigate/understand-dashboard.html["Explora tus datos"]
[role="quick-margin-para"]
Abre el panel para consultar información sobre la optimización del almacenamiento, o ve a link:../investigate/investigate-data.html["Investigación"] para buscar y filtrar tus metadatos directamente.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-5.png["Cinco"] link:../policies/create-policy.html["Crear una política"]
[role="quick-margin-para"]
Guarda tus filtros de investigación como una política para supervisar los archivos que cumplan los mismos criterios a lo largo del tiempo. Puedes configurar una política para enviar una notificación, eliminar definitivamente los archivos que cumplan los criterios o realizar un seguimiento de los resultados.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-6.png["Seis"] link:../mcp/quick-start-mcp.html["Opcional: configurar el acceso controlado a la IA"]
[role="quick-margin-para"]
Permite que los clientes de IA busquen en los metadatos de las colecciones que elijas. Los usuarios avanzados pueden buscar en los metadatos y realizar acciones con los datos.
